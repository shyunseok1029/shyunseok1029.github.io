## 프로젝트 소개

Node.js, Express, EJS와 Oracle Database를 사용하는 개인 게시판 프로젝트입니다. 제공받은 기본 게시판 구조를 바탕으로 기능을 확장하고 웹 애플리케이션의 인증·인가와 입력 처리 경계를 다뤘습니다.

## 주요 구현 내용

- **게시판 기능:** 회원 관리, 게시글 CRUD, 댓글·대댓글과 추천·비추천을 구현했습니다. 검색·정렬·페이지네이션과 내 활동을 지원합니다.
- **인증과 인가:** 세션 기반 인증과 서버 측 작성자 확인을 적용했습니다. 신규·변경 비밀번호는 salt와 `scrypt`로 해시하고 기존 SHA-512 해시 검증을 지원합니다.
- **요청 보호:** 상태 변경 요청에 CSRF 토큰을 확인하고 주요 사용자 입력은 SQL 바인딩 변수로 전달합니다.
- **첨부파일:** 파일 크기·확장자·일부 시그니처를 검사하고 정적 공개 경로 밖에 저장합니다. 이 검사는 완전한 콘텐츠 검증이나 악성 파일 검사가 아닙니다.

## 결과 및 검증

격리된 Oracle XE 21c에서 회원·게시글·댓글·반응, 검색·정렬, TXT 첨부와 인증·인가·CSRF 차단을 확인했습니다. 별도 모의 Oracle 테스트 20개가 통과했으며, 헤드리스 브라우저로 일부 화면을 확인했습니다. 실제 Oracle에서 다른 파일 형식, 여러 페이지의 검색 경계와 전체 브라우저 흐름은 추가 검증이 필요합니다. 비밀번호 재설정은 안전한 본인 확인 수단이 없어 비활성화되어 있습니다.
