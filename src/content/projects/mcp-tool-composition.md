## 프로젝트 소개

다중 MCP 도구 조합에서 나타나는 위험 경로와 실행 통제를 살펴보는 캡스톤 팀 연구입니다. 공개 프로필에 Python, Docker, uv, pytest를 사용하는 진행 중인 연구로 소개되어 있습니다.

## 주요 구현 내용

공개 자료는 위험 경로 분석과 실행 통제 평가라는 연구 방향을 설명합니다. 세부 구현이 공개되지 않아 아래는 완료된 작업이 아닌 검토할 연구 질문입니다.

- **도구 조합:** 여러 도구의 입력과 출력이 연결될 때 어떤 위험 경로가 생기는지 살펴봅니다.
- **분석과 실행:** 정적 분석과 실제 실행을 통한 검증을 각각 어떻게 적용할 수 있을지 검토합니다.
- **정책 기반 통제:** 위험한 도구 조합의 실행을 정책으로 제어할 수 있는지 살펴봅니다.

## 결과 및 검증

각 방법의 구현·실행 여부와 구체적인 결과는 아직 공개되지 않았습니다. 공개 가능한 설계와 평가 자료가 정리되면 검증 범위를 추가할 예정입니다.
